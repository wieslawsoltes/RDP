# Bulk decompression and source recovery

Source provenance: only the 0.1.0 source bundle was recoverable. Previous
continuation reports were not source code and are not evidence of implementation.

This change independently implements MPPC 8/64 KiB decoding and negotiates RDP5
as the highest bulk package. RDP6/NCRUSH and RDP6.1/XCRUSH are NOT advertised.
Slow-path Share Data, fast-path update fragments and static virtual-channel
fragments use one connection-scoped receive history, per MS-RDPBCGR 3.1.8.1.
Decoded output is owned. Overlapping references replicate byte-by-byte. Flushes
zero all history; corruption poisons the decoder until an explicit flush. Raw
packets never enter compressed history. Session disposal clears the history.

Also fixes Play Sound dispatch (type 34, not shutdown type 36), decodes server
status separately, advertises the implemented beep capability, and respects
bounded virtual-channel suspend/resume queues. Raw Share Data accepts either
full-PDU or Share-Data-only lengths; outgoing packets use full-PDU lengths.

Tests cover both MPPC tables, all literal values, offset/length boundaries,
published compression examples, overlapping copies, flush/front semantics,
malformed tokens, output ownership, shared history across transports, fragmented
updates and an activated-session wire test. They do not prove Windows interoperability.
